# 🎮 Gaming Analysis Dashboard using Power BI

## 📌 Project Overview

The **Gaming Analysis Dashboard** is a data visualization and business intelligence project developed using **Microsoft Power BI**.

The main purpose of this project is to analyze gaming data and identify useful insights related to **game sales, platforms, genres, publishers, release years, regions, and overall gaming trends**.

The project transforms raw gaming data into an interactive Power BI dashboard that helps users understand the performance of different games and gaming categories.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze the overall performance of video games.
- Identify the most successful games based on sales.
- Analyze game sales across different platforms.
- Compare sales across different genres.
- Analyze regional sales such as North America, Europe, Japan, and other regions.
- Identify top-performing publishers.
- Study gaming trends over different years.
- Create interactive visualizations using Power BI.
- Convert raw data into meaningful business insights.

## 📊 Dataset

The dataset contains information about video games and their sales performance.

### Important Columns

Some of the major columns used in the analysis include:

- **Rank** – Ranking of the game based on sales.
- **Name** – Name of the video game.
- **Platform** – Gaming platform on which the game was released.
- **Year** – Year in which the game was released.
- **Genre** – Genre/category of the game.
- **Publisher** – Company that published the game.
- **NA_Sales** – Sales in North America.
- **EU_Sales** – Sales in Europe.
- **JP_Sales** – Sales in Japan.
- **Other_Sales** – Sales in other regions.
- **Global_Sales** – Total global sales.

> **Note:** The exact columns may vary depending on the dataset used in the project.
